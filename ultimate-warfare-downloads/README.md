# Ultimate Warfare — комплект прототипа 0.1.12

[Скачать исходный комплект](https://raw.githubusercontent.com/AddemyMax/message-editor/uw-mod-download/ultimate-warfare-downloads/UltimateWarfare-0.1.12-source.zip).

Распакуйте отдельно и откройте папку `UltimateWarfare-0.1.12`. Выполните в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Mod.ps1 -GameDir "C:\Program Files (x86)\R.G. Mechanics\Command and Conquer - Generals\Command and Conquer Generals Zero Hour"
```

При заполненном меню обычного китайского завода сборщик сохраняет исходные команды и добавляет свободную ячейку 15 вместе с частным оверлеем стандартного интерфейса. Производственные кнопки становятся немного уже, точка сбора и продажа остаются на прежних местах. Поддерживается только подтверждённая стандартная разметка; занятые дополнительные ячейки и нестандартные панели вызывают отказ.

124 автоматических теста прошли на авторских синтетических данных, модель проверена. Сборка на реальных данных, внешний вид панели и игровой запуск пока не подтверждены. При ошибке передайте строку `ERROR:`. Нужен Python 3.10+.

Файлы установки игры не изменяются. ZIP содержит только исходники и авторские ресурсы, без оригинальных архивов, конфигураций и исполняемых файлов игры. Частный BIG и UI-оверлей создаются локально, вне установки.
