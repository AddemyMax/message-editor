# Ultimate Warfare — комплект первого прототипа

Эта отдельная ветка предназначена для передачи файлов мода; приложение message-editor не изменено.

- `UltimateWarfare-0.1.4-source.zip` — исходный комплект мода для оригинальной Zero Hour 1.04.
- `uwlongma-preview.png` — оригинальный рендер модели «Лунма» в Blender; игровой запуск ещё не проверен.

Откройте нужный файл на GitHub и нажмите **Download raw file** (значок скачивания). Для архива нужен именно ZIP этой папки, а не общий архив React-репозитория.

Распакуйте ZIP и откройте вложенную папку `UltimateWarfare-0.1.4`, где находятся `README.md`, `scripts`, `tools` и `content`. Откройте в ней PowerShell и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Prepare-Test.ps1 -GameDir "C:\Program Files (x86)\R.G. Mechanics\Command and Conquer - Generals\Command and Conquer Generals Zero Hour"
```

Для диагностики и сборки нужен Python 3.10+. Оригинальные файлы игры не перезаписываются. Нативные испытания Zero Hour и Windows-скриптов ещё не выполнены; 86 автоматических тестов инструментов проходят на синтетических данных.

SHA256 ZIP: `64cd5be883636ce0fe03365393d71ec71ce8340b48cb8f207c32fd35606fd754`

ZIP не содержит оригинальные игровые архивы, исполняемые файлы или локально собранный BIG. Код и документация — MIT; авторская геометрия и изображения — CC0-1.0. Полные условия находятся в LICENSE и docs/assets.md исходного комплекта.

Версия 0.1.4 исправляет чтение неиспользуемых движком полей заголовка BIG и добавляет имя проблемного архива и причину в archive_error. Если диагностика снова остановится, передайте только новый JSON, а не игровые архивы.

В 0.1.4 также исправлено чтение виртуальных имён исходного BIG со специальными символами Windows. Извлечение этих записей на диск не выполняется; строгие правила для создаваемого BIG сохранены.

В 0.1.4 несогласованные записи исходного каталога отмечаются предупреждением. При запросе их данных проверка физических границ обязательна и выполняется до чтения; некорректный необходимый источник нельзя пропустить или заменить. Отчёт включает версию проекта и параметры проблемной записи.
